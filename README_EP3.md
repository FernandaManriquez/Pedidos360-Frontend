# Pedidos360 Frontend - EP3

## Ejecutar
Requiere Node.js compatible con Angular.
Instalar: npm ci
Iniciar: npm start
Abrir http://localhost:4200
Compilar: npm run build

## Uso
Iniciar primero los servicios del backend y RabbitMQ.
El BFF local usa http://localhost:8080.
Iniciar sesion con Microsoft Entra ID.
En Pedidos, completar usuario, producto y cantidad.
Crear una vez y comprobar la nueva fila.
Tickets y notificaciones se generan en servicioNotificaciones/output del backend.
Consultar README_EP3.md del backend para sus requisitos.
